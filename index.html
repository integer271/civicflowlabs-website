01 / 문제의식

교통 혁신의 속도와
이동 기회의 격차

개인화되는 이동, 여전히 남아 있는 교통 사각지대
농촌과 차량 없는 가구, 고령자에게 필요한 것은 생활을 이어주는 교통서비스

PROBLEM 01

이동 접근성의 격차

분산된 이동 수요와 제한된 교통 공급 필요한 시간과 장소에 닿지 못하는 서비스

PROBLEM 02

분리된 운영 데이터

운행실적·이용 이력·공급정보의 분산 주민과 운송사업자에게 닿지 않는 운영정보

PROBLEM 03

서비스 품질의 사각지대

운행 건수만으로 드러나지 않는 대기시간, 접근성, 이용 편의
